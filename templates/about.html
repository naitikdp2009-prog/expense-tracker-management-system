DIPLOMA / DEGREE MINOR PROJECT REVIEW-2

EXPENSE TRACKER MANAGEMENT SYSTEM

A full-stack personal finance platform integrating RESTful Flask routes, SQLite storage, Chart.js analytics, rule-based AI insights, receipt parsing, and interactive purchase decision support.

1. Problem Statement

Users often record expenses manually on paper or use basic tracking applications that provide limited analytics and zero decision support. Traditional tools fail to warn users before budget limits are breached or offer objective purchase advice when considering non-essential expenses.

2. Proposed Solution

The proposed Expense Tracker Management System combines expense management, budget tracking, financial reporting, spending pattern analysis, receipt OCR handling, hands-free voice entry, and decision-support calculators (Purchase Advisor & What-If Simulator) into one unified offline platform.

6. Alternative Strategies / Fallbacks
  • If External AI API Unavailable: Use deterministic rule-based decision matrix.
  • If OCR Engine Fails: Fall back to interactive manual receipt correction form.
  • If PostgreSQL Unavailable: Use embedded lightweight SQLite database.
  • If Cloud Hosting Unavailable: Run locally on Flask development server.
  • If Voice Recognition Unsupported: Fall back to normal manual form entry.
